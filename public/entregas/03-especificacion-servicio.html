Importa preservar respuesta + estado posterior, incluidas las anomalías (typo recieved, espacio final de E301).

Especificación de servicio reimplementable. Cada comportamiento tiene un ID, su descripción, la evidencia (IDs exactos de experimentos.jsonl) y su confianza. Permite a otro ingeniero reimplementar el servicio sin tocar el original.

  • confirmado: probado y se repite en corridas distintas.
  • probable: visto una vez o inferido de la evidencia.
  • supuesto: no probado; es el default del reemplazo.

La evidencia se verifica automáticamente con reto2-investigacion/scripts/validar_spec.py: comprueba que cada ID citado existe y que la respuesta observada corresponde al comportamiento.

Secuencias del log: integridad (1–16), aridad (17–46), alta (47–57), consulta (58–64), deposito (65–86), transfer (87–100), anula (101–116), estado (117–121), bordes (122–163), bloqueo (164–239), bloqueo3 (240–278), max (279–290), sugerencia (291–308), bloqueo4 (309–336), sugerencia2 (337–347), gaps (348–366).

def digitos(cuerpo):
    out = []
    for c in cuerpo:
        if c.isdigit() and c.isascii(): out.append(c)
        elif c.isascii() and c.isalpha(): out.append(str(ord(c.upper()) - 64))
    return "".join(out)

def control(cuerpo):
    r = 0
    for d in digitos(cuerpo): r = (r * 10 + int(d)) % 97
    return 98 - (r * 100) % 97

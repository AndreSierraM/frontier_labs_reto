La Caja Negra Reemplazo HTTP compatible · Vigilancia y adaptación autónoma

Reconstruimos el contrato observable de un servicio heredado sin acceso a su código, lo reemplazamos sin romper a sus clientes y le enseñamos a adaptarse solo cuando el original cambia.

Frontier Labs · Reto 2

01 · El Contexto

El Problema

Sin visibilidad

Servicio crítico sin documentación ni código accesible. Comportamiento descubierto a ciegas comparando entradas y salidas.

Sin especificación

20 ejemplos oficiales desfasados (v1) mientras el servicio ya corría en v2. Nadie sabía qué reglas aplicaba realmente.

Sin adaptación

Si el servicio cambia sus reglas en producción, los sistemas dependientes rompen. No hay mecanismo de detección ni corrección.

El reto: reconstruir el contrato, reemplazar el servicio y sobrevivir a un cambio de contrato en producción sin tocar el original.

02 · La Solución

Tres capas

A · Reemplazo compatible

  • Máquina de estados pura (domain.js) separada de HTTP.
  • Dígito de control ISO 7064 MOD 97-10 (cracking 34/34).
  • Regla antifraude oculta descubierta: E510 tras 3 fallos.
  • Byte exacto: mismos status, headers y cuerpo JSON.

B · Vigilancia

  • Monitor cada 10 min: 31 puntos + mapa ampliado 101 sondas.
  • Snapshots y eventos en Neon Postgres.
  • Detecta comandos nuevos, rutas nuevas y valores cambiados.
  • Respeto de rate-limit; filtra infra para no perder cambios reales.

C · Enjambre de agentes

  • Scouts ×2 investigan en paralelo.
  • Analista decide si hace falta parche.
  • Fixer edita código + tests + SPEC.
  • Verificador exige 0 divergencias vs el original.
  • Reviewer gate + Reporter abre PR automático.
Monitor detecta cambio → Scouts → Analista → Fixer → Verif. → Reviewer → PR

Merge manual del PR dispara deploy en Vercel. La máquina propone; el humano decide.

Adaptador HTTP reutilizable. Dominio sin efectos secundarios. Persistencia con SELECT ... FOR UPDATE para serializar escrituras. El catálogo de sondas es auto-ensanchable: cada comando nuevo que fija el enjambre se convierte en regresión automática.
